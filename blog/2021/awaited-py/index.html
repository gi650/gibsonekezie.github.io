Difference between Synchronous Code Execution and Asynchronous Code Execution

Synchronous code execution is the basic python code execution we are familiar with. It means code execute in a strict sequence and the running code blocks everything else until completion (blocking behavior); Example of Basic Python Function (Synchronous Code)
